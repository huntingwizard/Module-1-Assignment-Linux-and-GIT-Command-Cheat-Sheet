Git
1. Creating a new Branch: git branch "branch name"
2. Switch to new Branch: git checkout "branche name"
3. Retrieve entire repository: git clone "url"
4. Merge branch into current branch: git merge "branch name"
5. Show all commits in current branch history: git log

Linux
1. Remove directory and everything in it: rm -rm "directory/file name"
2. View Current Directory: ls
3. Move into new Directory: cd [path to directory from current directory]
4. move out of current directory: cd ..
